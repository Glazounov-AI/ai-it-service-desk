# F3 — архитектура AI IT Service Desk

Согласовано 25.11.2026. Базовый коммит Service Desk: 3208f08. Целевая версия: v2.0.0.

Service Desk — самостоятельное приложение Python 3.14 / FastAPI / Pydantic / HTTPX. RAG Assistant остаётся отдельной универсальной платформой. Существующие 16 документов, промпт, CSV маршрутизации и 22 сценария сохраняются.

SQLite через слой доступа хранит сессии, историю и черновики. Классификация гибридная: правила, LLM, валидация допустимых категорий. Группа поддержки определяется таблицей маршрутизации. Код управляет состояниями new, clarifying, troubleshooting, awaiting_result, resolved, escalation_required, ticket_draft_ready, closed. Черновики сохраняются локально, внешней отправки нет.

## Контракт интеграции F3.2

RAG POST /query принимает query и mode. Профиль it_service_desk: максимум 2000 символов, 5 запросов в минуту, кэш и логирование содержимого отключены. X-API-Key передаётся при настройке ключа. История отдельным полем не поддерживается. Решение о передаче контекста отложено до F3.3; RAG не меняется.

Локальный GET /health проверяет только доступность приложения. POST /consult — временный диагностический endpoint, без сессий и классификации. Только loopback, синтетические запросы без персональных данных и секретов. Не публиковать до реализации безопасности и контроля доступа. HTTP 429/504 передаются в нормализованном виде; сетевые ошибки 503, остальные ошибки upstream 502. Общий таймаут обращения к RAG 25 секунд, без автоматических повторов. Это не гарантия полного SLA. Настройки через переменные окружения; .env.example — справочник, автоматической загрузки .env нет. HTTPX не использует системные proxy-переменные.

Предварительная проверка: 12 тестов с MockTransport; реальный API и Python 3.14 проверяются отдельно. Зависимости заданы диапазонами, фиксация версий после проверки окружения.
