# F3.4.5–F3.4.6-final

Corrective patch following the first integration run. The threshold is configurable (SERVICE_DESK_GENERATION_CONFIDENCE_THRESHOLD, default 0.8), provisional and not calibrated. Validated taxonomy and rule conflicts remain mandatory. Out-of-scope results are accepted only without taxonomy fields and without conflict with the baseline IT domain. In hybrid mode out-of-scope replies are local.

Classification metadata includes generation_reason, generation_http_status and generation_usage. For transport errors the status is a locally mapped 503/504, not a received HTTP status. Usage is separate from retrieval usage, including rejected candidates when a valid generation envelope is received. Empty usage means unavailable, not necessarily zero cost. Logs contain reason and status only, not request text or keys. Existing RAG API and timeouts unchanged. Context is used for classification only, not retrieval. User message metadata remains baseline; assistant metadata records final classification.

Local regression: 92 tests passed under Python 3.13.5. Target Python 3.14.4 and live integration still require acceptance. The original missing access log has not been conclusively explained. No production readiness claim.
