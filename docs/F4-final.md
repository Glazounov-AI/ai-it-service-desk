# F4C-final — локальная функциональная приёмка

Базовая регрессия F4C: 188 тестов подтверждены пользователем на Python 3.14.4. Заключительный пакет: 198 тестов на Python 3.13.5 (4.71 с), включая 10 новых сценариев с SQLite и имитацией RAG. Повторная локальная проверка на 3.14.4 необходима.

- D28: отдельные действия проверки резервного MFA и входа; второй ответ «Да» подтверждает вход, отрицательный ответ передаёт специалисту, два нераспознанных ответа завершают ветку эскалацией.
- D29: исчерпание действий без подтверждения устранения приводит к эскалации, а не ожиданию без активного действия.
- D30: завершённые проверки и выполненные действия учитываются в troubleshooting_completed. Это признак прохождения предусмотренных действий, не подтверждение устранения проблемы. Для TS-022 сохранён прежний критерий двух основных действий VPN.
- D18: недоступные сведения сохраняются в черновике; проверены три варианта сбора названий ресурсов. Произвольный текст и достоверность сообщённых сведений не верифицируются.

Ограничения: тесты не используют живой OpenAI; все варианты естественного языка и старые незавершённые сессии не проверены. Нет аутентификации, отправки заявок и полной оценки производительности. Публичное развёртывание запрещено до реализации защиты. F5 — надёжность, безопасность, измерение задержек и затрат.
