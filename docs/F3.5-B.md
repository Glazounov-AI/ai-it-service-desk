# F3.5-B — managed diagnostics (development)

Enable SERVICE_DESK_MANAGED_DIAGNOSTICS=true for session messages. Default false preserves legacy behavior; /consult remains unchanged. Requires F3.5-A and targeted RAG patch. Local CSV selects routing and exact KB filename. First diagnostic action requires a successful targeted retrieval; subsequent actions use trusted CSV instructions, not generated prose. Upstream usage and sources are retained, but the displayed instruction is local. No automatic ticket submission.

State, assistant message and transition are committed together; the user message is persisted before external calls. One action at a time. Explicit short confirmations are recognized by conservative rules; other replies request clarification. VPN reconnect is prioritized for RESOURCE_ACCESS. A new issue requires a separate session. User evidence is verbatim, not independently verified. General atomic fact extraction and arbitrary paraphrase handling remain incomplete. Conditional administrative routing and all 22 scenario acceptance are not yet verified. No public authorization is provided. The targeted call currently incurs generation cost even though its prose is not used; optimize in F5. Tests use mocked HTTP, not live Chroma/OpenAI.
