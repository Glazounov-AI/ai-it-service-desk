# F4C — комплексная приёмка

188 тестов в среде Python 3.13.5, включая 18 новых. Целевая среда Python 3.14.4 требует повторного запуска.

16 сценариев через FastAPI TestClient с отдельной SQLite БД и MockTransport: классификация, последовательность действий без повторов, эскалация, статья, группа, идемпотентность черновика. KB-002 и KB-012 сразу эскалируются, KB-005 проверяется по ветке отсутствия резервного метода. Два сценария восстановления после HTTP 503/504 в той же сессии. Реальный OpenAI API не вызывается.

## Ограничения аудита

- D18: сбор информации ограничен шаблонами; типизация привязана к порядку CSV. Сведения не являются независимо проверенными фактами.
- D26/D27: исправления проверены на известных формулировках, не на произвольном языке.
- MFA: специальная ветка не различает все этапы резервного входа, повтор «Да» может повторять инструкцию; требуется исправление.
- Последнее действие с результатом unknown/check_positive может оставить сессию awaiting_result без ожидающего действия; требуется проверка и исправление.
- troubleshooting_completed учитывает только not_resolved, поэтому выполненные проверки с другими результатами могут не учитываться.
- Живые испытания и браузерная приёмка отдельно; публичный доступ запрещён до авторизации.

F4C не является окончательной приёмкой до устранения выявленных блокеров и подтверждения целевой среды.
