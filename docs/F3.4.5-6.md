# F3.4.5–F3.4.6 — hybrid classification foundation

Opt in with SERVICE_DESK_GENERATION_ENABLED=true and SERVICE_DESK_GENERATION_KEY matching RAG_GENERATION_ACCESS_KEY. Point RAG_GENERATION_PROFILES_DIR to this repository's generation/profiles directory. Default is disabled. Generation timeout defaults to 10 seconds; combined asynchronous work is bounded to 28 seconds. No retries. Existing database schema is unchanged.

Rules and safety take precedence. Only unresolved classifications invoke generation. Accept only complete valid IT taxonomy pairs with confidence >= 0.85 and no conflict with a known baseline category. Priority and KB availability are derived locally. Other results or upstream errors retain baseline clarification. Confidence is heuristic. Context is limited to six recent messages, 600 characters each, 2400 total, with flagged messages omitted. Context is sent to classification only, not RAG retrieval. User metadata retains initial classification; assistant metadata records final classification. This is not full conversational troubleshooting: follow-up RAG queries still use current text only. No guarantee of complete secret detection. The 28-second asynchronous budget excludes synchronous database operations and HTTP overhead. No production latency guarantee.

Tests use mocked upstream; real provider and independent quality evaluation remain pending.
