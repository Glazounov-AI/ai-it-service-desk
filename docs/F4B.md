# F4B — диагностическая панель

Интерфейс читает существующие GET diagnostic-case и ticket-draft после обновления истории. 404 означает отсутствие объекта; остальные ошибки отображаются отдельно. Старые карточки очищаются при смене/обновлении сессии. Данные выводятся через textContent. Черновик копируется как JSON, не отправляется. Сведения пользователя не являются независимо проверенными фактами. При узком окне панели располагаются под чатом. API, БД и зависимости не меняются. Браузерная проверка требуется; тесты API не заменяют её. Копирование зависит от разрешения браузера. D18 и ограничения MFA сохраняются.
