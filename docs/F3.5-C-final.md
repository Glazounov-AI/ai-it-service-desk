### Known limitations

D18: diagnostic action result validation.

The current implementation can interpret a generic failure
response as completion of an information collection action.

For example, the action requesting the names of unavailable
corporate resources can be marked completed without receiving
the actual resource names.

Ticket draft completeness validation must distinguish confirmed
facts, reported actions and missing information.

Additional limitations:

- Diagnostic preflight recognizes a limited set of explicit phrases.
- Confirmed facts currently store user statements rather than
  normalized atomic facts.
- Managed diagnostics remain opt-in.
- Full performance, timeout and token optimization remain in F5.
- Ticket draft creation remains in F3.6.
