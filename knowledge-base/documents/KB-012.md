# KB-012 — Запрос на установку программы

## category

SOFTWARE

## subcategory

INSTALL_REQUEST

## symptoms

Пользователю требуется дополнительное программное обеспечение

## environment

Managed Windows Workstation

## os_version

WIN10|WIN11

## user_actions

Проверить наличие приложения в корпоративном каталоге разрешённого ПО
- Если приложение доступно использовать стандартную процедуру установки
- Если приложения нет в каталоге не устанавливать его из сторонних источников

## expected_result

Разрешённое приложение установлено стандартным способом

## escalation_condition

Приложение отсутствует в корпоративном каталоге или установка требует административных прав

## support_group

Workplace
