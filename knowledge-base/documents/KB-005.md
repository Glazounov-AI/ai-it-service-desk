# KB-005 — MFA после замены телефона

## category

MFA

## subcategory

PHONE_REPLACED

## symptoms

Пользователь заменил телефон и не может подтвердить вход

## environment

Microsoft 365 / MFA

## os_version

ALL

## user_actions

Проверить доступность ранее настроенного резервного способа подтверждения
- Если резервный способ доступен использовать его для входа
- Не удалять существующие методы MFA без подтверждённого доступа к учётной записи

## expected_result

Пользователь подтверждает вход резервным способом

## escalation_condition

Нет доступного способа подтверждения или требуется перерегистрация MFA

## support_group

Identity & Access
