# KB-004 — Не приходит код MFA

## category

MFA

## subcategory

CODE_NOT_RECEIVED

## symptoms

Пользователь не получает код подтверждения при входе

## environment

Microsoft 365 / MFA

## os_version

ALL

## user_actions

Проверить выбранный способ подтверждения
- Проверить доступность зарегистрированного телефона
- Подождать повторной отправки кода
- Запросить новый код один раз

## expected_result

Код получен и вход успешно подтверждён

## escalation_condition

Код повторно не приходит или зарегистрированное устройство недоступно

## support_group

Identity & Access
